# Read_It

Расширение для Firefox, которое читает вслух выделенный текст на русском.
Используется встроенный **Web Speech API** — никаких внешних сервисов и сетевых запросов.

> Исходный «vibecode» не работал «из коробки». Версия в `text-reader/` —
> исправленная и проверенная. Собранный плагин: `read-it-1.2.xpi`.

## Что добавлено (против оригинала)

| Фича | Статус | Как работает |
|------|--------|--------------|
| Горячая клавиша **Alt+R** | ✅ | `manifest.json` → `commands` + `browser.commands.onCommand` в `background.js`. Читает текущее выделение. |
| **Выбор голоса** из списка | ✅ | Попап запрашивает список голосов у content-скрипта (`getVoices`), сортирует русские вверх; выбор хранится в `storage`. |
| **Подсветка читаемого слова** | ✅ | `utterance.onboundary` (Firefox 49+) → подсветка через CSS Custom Highlight API (Firefox 140+) с фолбэком на `<mark>`. |
| **Сохранение** | ⚠️ см. ниже | Кнопка «Сохранить текст» выгружает выделение в `.txt`. |

### Почему нет MP3
Web Speech API **не отдаёт аудиопоток** и не умеет сохранять файл — экспорт
в MP3 чисто на нём невозможен (нет `MediaStream`, нет записи синтеза).
Поэтому «Сохранить» выгружает сам текст. Если нужен именно звуковой файл,
вариант — добавить офлайн-TTS-движок в WASM (например, espeak/speak.js) и
кодировать в MP3 через lame.js. Это уже другой движок речи, не Web Speech API,
и заметно больше по весу — скажите, если нужно, сделаю отдельной правкой.

## Структура

```
text-reader/
├── manifest.json      (+ commands, permission "storage")
├── background.js      (+ горячая клавиша Alt+R, чтение настроек)
├── content.js         (+ выбор голоса, подсветка слова, отдача текста)
├── popup.html         (+ <select> голоса, кнопка сохранения)
├── popup.js           (+ список голосов, storage, сохранение .txt)
├── popup.css
└── icons/icon.svg
```

## Установка (временная, для разработки)

1. Откройте `about:debugging` в Firefox.
2. Слева — «Этот Firefox».
3. «Загрузить временное дополнение…» → выберите `read-it-1.2.xpi`
   (либо `text-reader/manifest.json`).

Готово! Выделите текст на странице и:
- **ПКМ → «🔊 Прочитать выделенное»**, или
- откройте попап расширения → «▶ Прочитать (Alt+R)», или
- нажмите **Alt+R**.

Ползунок «Скорость» и выбранный голос запоминаются (через `storage`),
поэтому горячая клавиша и контекстное меню используют ваши настройки.

## Проверено
- Синтаксис `manifest.json` и всех `.js` — `node --check` (OK).
- Сборка `.xpi` — обычный zip, `manifest.json` в корне (Firefox принимает).
